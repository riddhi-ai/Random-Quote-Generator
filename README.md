# Random Quote Generator

## Overview
The Random Quote Generator is a modern, user-friendly web application that displays motivational and reflective quotes through an intuitive interface.  
The application focuses on clean UI design, accessibility, and meaningful content that users can easily connect with.

## Quote Curation
Instead of relying on external APIs, this application uses a curated collection of quotes attributed to well-known public figures from sports, business, cinema, and thought leadership.  
These quotes are selected to reflect themes such as consistency, growth, resilience, self-awareness, and balance—ideas that resonate with a broad audience and ensure the application remains reliable and fully functional offline.

## Features
- Displays a randomly selected quote on each interaction
- Quotes attributed to recognized public figures
- Smooth fade-in animation when quotes change
- Animated gradient background for enhanced visual experience
- Glassmorphism-style card layout
- Dark mode support for better accessibility
- Share/copy quote functionality
- Fully functional without internet access

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## How to Run
1. Open the project folder.
2. Open `index.html` in any modern web browser.
3. Click **New Quote** to generate a quote.
